PIVOT TABLES & FIELD GRIDS

Summary aggregations & layouts

Concept & Syntax

Summarizes raw datasets into analytical reports. Fields map to Rows, Columns, Values, and Filters zones.

Command: Insert > PivotTable | Rows/Cols/Values
Where is it Used

Aggregating transaction records by region, evaluating sales representative metrics, and summarizing monthly trends.

Example Model: Regional Sales
Region (Rows) Sum of Sales (Values)
North120,000
Grand Total120,000
Pivot Grid: Rows = Region, Values = SUM(Sales) Aggregated
Common Mistakes Forgetting to click Refresh after updating source tables (Pivot Tables do not recalculate automatically).
Interview Prep Q: "What is the Pivot Cache?"
Expectation: It is a memory duplicate of the source dataset. It increases file size but allows fast layouts recalculations.
