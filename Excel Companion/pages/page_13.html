LEFT, RIGHT, MID, & LEN

Concept & Syntax

Extracts sub-strings based on character index coordinates and counts character lengths of database strings.

=MID(txt, start, chars) | =LEN(txt)
Where is it Used

Isolating dialing codes, parsing serial numbers batches, and checking database fields constraints limits.

Example Model: Code extraction
Serial (B) Code (LEFT)
IND-9921IND
=LEFT(B2, 3) IND
Common Mistakes Hardcoding string lengths when values vary (e.g., parsing names using fixed lengths). Forgetting spaces are counted.
Interview Prep Q: "How do you split a full name into First & Last name dynamically?"
Expectation: Combine LEFT/RIGHT with SEARCH: =LEFT(A2, SEARCH(" ", A2)-1) to extract up to the space delimiter.
