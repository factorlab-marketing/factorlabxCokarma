VLOOKUP REFERENCE

Vertical Database Key Matching

Concept & Syntax

Searches vertically down column 1 of a table range, locates matching key, and returns the value at a column offset index.

=VLOOKUP(lk_val, tbl_arr, col_idx, [match])
Where is it Used

Pulling unit prices from catalog files into active logs, and mapping customer names using unique transaction ID numbers.

Example Model: Salary Search
ID (A) Name (B) Salary (C)
E101Aarav65000
E104 (Key) Isha 75000 (Col 3)
=VLOOKUP("E104", A2:C3, 3, FALSE) 75000
Common Mistakes Forgetting FALSE/0 at the end, which defaults to sorted approximate match mode and returns incorrect coordinates. Column insertion breaks the static index parameter.
Interview Prep Q: "What are VLOOKUP's core structural limitations?"
Expectation: Explain that VLOOKUP cannot perform leftward lookups, search indices are static (broken by shifts), and sorting defaults to approximate matching without FALSE.
