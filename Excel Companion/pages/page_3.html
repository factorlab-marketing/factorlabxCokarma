Relative, Absolute, & Mixed References

Concept & Syntax

Controls coordinate drifting during drag calculations. Toggle reference states using F4.

Lock Typology
A1 Relative
$A$1 Absolute
A$1 Row Lock
$A1 Col Lock
Where & How: Tax Multipliers

Locking the tax rate coordinate cell (Absolute: $B$1) when projecting sales row logs.

Common Mistakes Forgetting referencing locks during matrix drags, which shifts the lookup array and triggers `#N/A` errors.
Interview Prep Q: "How do $A1 and A$1 differ?"
Expectation: Explain that A$1 locks the row (remains vertical) and $A1 locks the column (remains horizontal). Essential for multiplication tables.
