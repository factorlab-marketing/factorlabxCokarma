CONDITIONAL FORMATTING RULES

Highlighting Values & KPI Alerts

Concept & Syntax

Applies cell highlights, fonts, borders, or progress data bars to ranges dynamically based on evaluation logic checks.

Command: Home > Conditional Formatting > New Rule
Where is it Used

Highlighting negative values in red, tracking overdue project statuses, and visual coding top 10% items.

Example Model: Late Invoices
Invoice ID Days Late
INV00145 (CF Highlight)
INV00212
Rule: Cell Value > 30 days Format: Light Red Fill
Common Mistakes Creating conflicting rules over overlapping ranges. Using high-saturation primary colors that clutter the report visuals.
Interview Prep Q: "What is a potential performance risk of Conditional Formatting?"
Expectation: CF is volatile and recalculates on every sheet action. Minimize rules and avoid applying them across entire columns.
