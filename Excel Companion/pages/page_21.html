MULTI-KEY CUSTOM SORTING

Layered sorting & Priority lists

Concept & Syntax

Reorganizes rows using multiple column rules hierarchically, or sorts text by non-alphabetical custom values lists.

Command: Data > Sort > Add Level | Custom Lists
Where is it Used

Ordering pipeline tasks by priority (High, Med, Low), and sorting rosters by department then by name.

Example Model: Task Sorting
Task Priority
Audit FileHigh (Sorted Level 1)
Design SlideMedium (Sorted Level 1)
Sort Level 1: Priority (High, Med, Low) Ordered
Common Mistakes Sorting only a single highlighted column and breaking row data associations. Failing to format mixed numbers/text columns.
Interview Prep Q: "How do you sort items in a custom order like priority?"
Expectation: Define a Custom List via Excel Options, then select this custom list under the Sort Options menu.
