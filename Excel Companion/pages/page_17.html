VALIDATION PROMPTS & ALERTS

Input tooltips & Error Alert dialogs

Concept & Syntax

Displays a guide message tooltip on cell selection and rejects invalid inputs with popup alert modals.

Options: Input Message | Error Alert (Stop)
Where is it Used

Guiding template users on valid codes, and rejecting values outside specified whole number ranges.

Example Model: Input messages
Tooltip:

"Enter score 0-100"

Error Modal:

"Invalid value"

Trigger Event: Invalid input value Alert Blocked
Common Mistakes Selecting Warning or Info alert types instead of Stop (Warning prompts alerts but allows users to click OK and force invalid data).
Interview Prep Q: "What is the difference between Warning and Stop validation alerts?"
Expectation: Stop alerts completely block invalid entry. Warning alerts display a warning but let the user override and save the invalid data.
