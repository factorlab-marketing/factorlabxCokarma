COUNTIF & COUNTIFS REFERENCE

Counting Records Under Constraints

Concept & Syntax

Counts the number of cells within evaluation ranges that satisfy criteria tests. Only requires rule array arguments.

=COUNTIFS(crit_range1, criteria1, ...)
Where is it Used

Calculating transaction volume metrics, tracking ticket queues, counting active client lists, and reporting dashboard checks.

Example Model: Paid Status Counts
Rep (B) Status (C)
RohanPaid
PriyaPending
=COUNTIFS(B2:B3, "Rohan", C2:C3, "Paid") 1
Common Mistakes Entering wildcards on number columns. Text comparison quotes omission. Mismatched column range height metrics, yielding errors.
Interview Prep Q: "How do you count duplicate items in a list?"
Expectation: Explain that entering the first cell as criteria in a relative drag range (e.g. =COUNTIF(A$2:A100, A2)) flags duplicates.
