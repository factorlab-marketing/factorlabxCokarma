CELL REFERENCE LOCKING

Relative, Absolute, & Mixed References

Concept & Syntax

Controls coordinate drifting during drag calculations. Toggle reference states using F4.

Lock Typology
A1 Relative
$A$1 Absolute
A$1 Row Lock
$A1 Col Lock
Where & How: Tax Multipliers

Locking the tax rate coordinate cell (Absolute: $B$1) when projecting sales row logs.

Sales (A) Tax Rate (B1) Output Tax (C)
120000 18% ($B$1) =A2*$B$1 21600
85000 =A3*$B$1 15300
Common Mistakes Forgetting referencing locks during matrix drags, which shifts the lookup array and triggers `#N/A` errors.
Interview Prep Q: "How do $A1 and A$1 differ?"
Expectation: Explain that A$1 locks the row (remains vertical) and $A1 locks the column (remains horizontal). Essential for multiplication tables.

VLOOKUP REFERENCE Finding Data

VLOOKUP REFERENCE

Vertical Database Key Matching

Concept & Syntax

Searches vertically down column 1 of a table range, locates matching key, and returns the value at a column offset index.

=VLOOKUP(lk_val, tbl_arr, col_idx, [match])
Where is it Used

Pulling unit prices from catalog files into active logs, and mapping customer names using unique transaction ID numbers.

Example Model: Salary Search
ID (A) Name (B) Salary (C)
E101Aarav65000
E104 (Key) Isha 75000 (Col 3)
=VLOOKUP("E104", A2:C3, 3, FALSE) 75000
Common Mistakes Forgetting FALSE/0 at the end, which defaults to sorted approximate match mode and returns incorrect coordinates. Column insertion breaks the static index parameter.
Interview Prep Q: "What are VLOOKUP's core structural limitations?"
Expectation: Explain that VLOOKUP cannot perform leftward lookups, search indices are static (broken by shifts), and sorting defaults to approximate matching without FALSE.

EXCEL REFERENCE DECK 05
XLOOKUP REFERENCE Finding Data

XLOOKUP REFERENCE

Modern and Versatile Lookup Engine

Concept & Syntax

Modern, robust replacement for VLOOKUP. Searches any direction, defaults to exact match, and provides custom search modes.

=XLOOKUP(val, lk_arr, ret_arr, [empty], [match])
Where is it Used

Searching leftward (finding keys left of lookup ID), reverse searching from bottom-to-top, and setting up fallback strings natively.

Example Model: Leftward search
Salary (A) Name (B) Employee ID (C)
75000 (Return) Isha E104 (Lookup)
=XLOOKUP("E104", C2:C2, A2:A2, "Missing") 75000
Common Mistakes Range size mismatches (lookup and return ranges must be the exact same width or height, or it throws `#VALUE!`). Older Excel versions lack the function.
Interview Prep Q: "Why is XLOOKUP superior to VLOOKUP in dynamic sheets?"
Expectation: Detail that it is insertion-safe, performs leftward searches, defaults to exact matches, and natively manages empty values.

EXCEL REFERENCE DECK 06
INDEX + MATCH REFERENCE Finding Data

INDEX + MATCH REFERENCE

Two-Dimensional Grid Coordinates Lookup

Concept & Syntax

Combines INDEX (retrieves value at offset row index) and MATCH (calculates row offset number of matching target value).

=INDEX(ret_range, MATCH(lk_val, lk_range, 0))
Where is it Used

Two-way intersection lookups, and building high-performance, insertion-safe models in legacy Excel environments.

Example Model: Salary Lookup
Salary (A) Employee ID (B)
75000 (INDEX Target) E104 (MATCH Key)
=INDEX(A2:A2, MATCH("E104", B2:B2, 0)) 75000
Common Mistakes Mismatching range shapes between INDEX array and MATCH array skews result alignment. Forgetting 0 in MATCH triggers wrong relative offsets.
Interview Prep Q: "How does INDEX + MATCH optimize calculation speeds?"
Expectation: Explain that unlike VLOOKUP, INDEX+MATCH only loads target search columns rather than scanning full table arrays, reducing memory overhead.

IF & IFS LOGICAL BRANCHING Formulas & Logic

IF & IFS LOGICAL BRANCHING

Logical Testing & Segmentations

Concept & Syntax

Evaluates conditional tests and returns specified values. IFS checks multiple criteria in sequence and stops on the first True logic.

=IFS(t1, v1, t2, v2, ..., TRUE, default)
Where is it Used

Segmenting customers into priority tiers, defining transaction commission thresholds, and wrapping calculations in error handlers.

Example Model: Sales Tiers
Sales (B) Commission (C)
12000012000 (10%)
450000 (0%)
=IFS(B2>=100000, B2*10%, B2>=50000, B2*5%, TRUE, 0) 12000
Common Mistakes Out-of-order check limits inside IFS (placing lower thresholds before higher ones, e.g. B2>=50000 before B2>=100000 triggers wrong commissions).
Interview Prep Q: "How do you simplify nested IF statements?"
Expectation: Advise moving to IFS to keep formulas clean, or utilizing lookup tables with approximate matches for multi-tier criteria mappings.

SUMIF & SUMIFS REFERENCE

Summing Values Matching Conditions

Concept & Syntax

Adds numbers inside a sum range that satisfy criteria conditions. SUMIFS handles multiple rules and places the sum range first.

=SUMIFS(sum_range, crit_range1, criteria1, ...)
Where is it Used

Consolidating department expenditure logs, summing regional sales metrics, and updating monthly KPI charts dynamically.

Example Model: Sales Sums
Dept (B) Sales (C)
Analytics120000
Finance85000
=SUMIFS(C2:C3, B2:B3, "Analytics") 120000
Common Mistakes Mismatched range sizes between sum and criteria arrays skews calculation offsets. Forgetting to lock ranges during formula drag.
Interview Prep Q: "What is the difference in range placement between SUMIF and SUMIFS?"
Expectation: Explain that SUMIF places the optional sum range last, whereas SUMIFS puts the sum range first. Point out that SUMIFS is preferred.

DATE CALCULATIONS & SERIALS

TODAY, DATE, & DATEDIF

Concept & Syntax

Excel stores dates as sequential integers (serial days since 1/1/1900). DATEDIF computes exact time intervals.

Tracking employee tenure milestones, age categorizations, and setting contract deadline warnings dashboards.

Example Model: Tenure Check

15-07-202121-05-2026
