Formula Engine Math & Stats

Basic Math & Aggregations

Syntaxes & Parameter Reference

SUM / SUMIF =SUMIF(range, criteria, [sum_range])

Adds values meeting criteria. Business: calculating category cost aggregates.

Mistake: Single SUMIF forces sum target to the end, opposite of SUMIFS.
SUMIFS / COUNTIFS =SUMIFS(sum_range, crit_range, criteria, ...)

Multi-criteria sums/counts. Business: regional branch item quantities.

Mistake: Mismatched criteria array lengths resulting in #VALUE! errors.
AVERAGEIFS =AVERAGEIFS(avg_range, crit_range, criteria, ...)

Averages cells by rules. Business: computing mean rep sales bounds.

Formula Engine Lookups

Lookup Comparison

VLOOKUP vs. XLOOKUP vs. INDEX MATCH

Capability VLOOKUP XLOOKUP INDEX MATCH
Look Leftward? No Yes Yes
Column Insert Safe? No Yes Yes
Approx Match? Yes Yes Yes
Calculation Speed Moderate Fast Fast
Data Type Locks? Yes Yes Yes
Analyst Conclusion

Use **XLOOKUP** as your primary choice. If sharing models with legacy Excel versions (2019 and older) that do not support XLOOKUP, build with **INDEX MATCH** to prevent formula execution failure.

Diagnostics & Resolution Reference

Error Meaning Fix Action
